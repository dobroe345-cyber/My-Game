# 🧠 Brainrot Vault — Telegram Mini App

Кейсы, апгрейд, магазин, профиль из Telegram, пополнение за ⭐, промокоды, роли и вывод брейнротов в Roblox.
Весь сервер — один файл `server.py` (только стандартная библиотека Python, ничего устанавливать не нужно).

## Запуск на Render (по шагам)
1. В Telegram: **@BotFather → /newbot** → получи **токен**. Для оплаты звёздами больше ничего подключать не нужно.
2. Залей эту папку в **приватный** репозиторий GitHub. Токен в код не вставляй.
3. **render.com → New → Blueprint** → выбери репозиторий (файл `render.yaml` уже настроен).
   Если создаёшь вручную: Web Service, Start Command `python server.py`, тариф **Starter**, Disk 1 GB, Mount Path `/data`.
4. В Render → **Environment** задай: `BOT_TOKEN` = твой токен, `OWNER_USERNAME` = `Tuke5669`, `DB_PATH` = `/data/game.db`.
5. После деплоя открой бота → `/start` → кнопка **«Играть»**. Сервер сам ставит webhook и кнопку меню бота.
6. Зайди в игру со своего аккаунта `@Tuke5669` — появится вкладка **«Админ»** (владелец).

> ⚠️ **Не используй бесплатный тариф для настоящего бота.** Он засыпает (а Telegram ждёт ответ на платёж 10 секунд),
> и его файлы стираются при каждом деплое — пропадут балансы и инвентари игроков. Нужен Starter + Disk.

## Оплата звёздами ⭐
- Игрок нажимает **+** рядом с балансом → выбирает пакет → Telegram открывает счёт в ⭐.
- Курс по умолчанию: **1 ⭐ = 5 монет** (20 ⭐ = 100 монет). Меняется в Админ → Настройки.
- Бонус к депозиту из промокода применяется **один раз** к следующему пополнению: 20 ⭐ с +50% = 150 монет.
- Монеты зачисляются только после подтверждения платежа от Telegram; повторное зачисление одного платежа исключено.
- Заработанные ⭐ смотри и выводи через @BotFather (меню твоего бота, раздел с балансом звёзд).
- **Первую оплату проверь сам на 5 ⭐**, прежде чем запускать игроков.

## Промокоды и роли (Админ-меню)
Типы промо: **монеты**, **бесплатные открытия кейса**, **бонус к депозиту (%)**.

| Уровень | Название | Бонус к депозиту | Макс. активаций | Срок |
|---|---|---|---|---|
| 1 | Блогер | до 5% | 10 | 48 ч |
| 2 | Помощник | до 10% | 50 | 48 ч |
| 3 | Партнёр | до 25% | 100 | 48 ч |
| 4 | Владелец (ты) | любой | без лимита | без срока |

- Роль выдаётся по Telegram-username: **Админ → Персонал** (можно выдать тому, кто ещё не заходил — роль привяжется при первом входе).
- Роли ограничены принудительно: даже если указать больше, сервер поставит лимит уровня. Безлимит и срок «навсегда» — только у владельца.
- Для промо на монеты и кейсы у ролей свои потолки (по умолчанию: монеты 50/150/500, кейсы до 150/1500/10000 монет) — меняются в `ROLES` вверху `server.py`.
- **Админ → Персонал** показывает по каждому: сколько создал промо, сколько активаций, сколько разных людей и когда использовали (время). Повышение/понижение — кнопкой «Сохранить» с новым уровнем.
- Нельзя активировать свой промокод; один игрок — одна активация кода.

## Вывод брейнротов
- В профиле рядом с «Продать» есть **«Вывести»** (только для брейнротов от **300 монет**; обычные и редкие дешевле порога).
- Игрок вводит ник в Roblox → заявка (брейнрот резервируется) → тебе приходит сообщение от бота и заявка появляется в **Админ → Выводы**.
- Выдал в игре → нажми **«Выдан ✅»** (игроку придёт уведомление). Нет → **«Отклонить»** — брейнрот вернётся в инвентарь.

## Бесплатное
- Бонус монет, стартовый баланс и бесплатные кейсы включаются/выключаются в **Админ → Настройки** (когда уберёшь бесплатное — поставь 0).
- Кейс **«Подписка»** работает, если задан `TG_CHANNEL` (например `@mychannel`) и бот — админ канала. Кейсы **«По тегу»** и **«Поделись»** пока помечены «Скоро».

## Проверка на своём компьютере
```
DEV_MODE=1 BOT_TOKEN=000:test python server.py
```
Открой `http://localhost:8000/?dev=1001:myname` (id:username). `DEV_MODE` на сервере включать нельзя — он отключает проверку Telegram.

## Как устроено
- Вся игровая логика (кейсы, шансы, апгрейд, покупки, баланс) выполняется **на сервере** — клиенту ничего не доверяется. Сайт лишь показывает.
- Каждый запрос проверяется по подписи Telegram (`initData`), поэтому подделать чужой аккаунт нельзя.
- Цены и шансы кейсов: `static/catalog.json` (цены брейнротов) и функция `contents()` в `server.py` (средний возврат кейса 68%, апгрейд 90% от отношения ставки к цели).
